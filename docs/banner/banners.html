Duck Council banners

Every banner below is drawn at its exact final size. To save one as a PNG:

  1. Open this file in Chrome or Edge and press F12.
  2. In the Elements panel, find the banner's <div class="frame …"> (or right-click the banner, choose Inspect, and step up to the frame).
  3. Right-click that element and choose Capture node screenshot.

For a sharper image (recommended for GitHub), first open the device toolbar (Ctrl+Shift+M), set DPR to 2, then capture: you get a 2× PNG.
